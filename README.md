## ✨ Overview

> **Hotgi Creative OS** isn't just a portfolio — it's a fully interactive **web-based desktop operating system** that lives entirely in your browser. Draggable windows, a live taskbar, a Start Menu, a Control Panel, a boot sequence, and even an AI assistant — all wrapped around one goal: showcasing real work in the most immersive way possible.

## 🎬 What Makes It Different

<table>
<tr>
<td width="50%" valign="top">

### 🖱️ It's a Real Desktop
Draggable, resizable, minimizable, maximizable windows — powered by `jQuery UI` — with touch support for mobile. Every "app" is its own window, just like a real OS.

### 🚀 Animated Boot Sequence
A cinematic boot screen loads the system on every visit, complete with a progress bar and live status messages — *"Mounting portfolio drive…"*, *"Starting AI core…"*

### 🌌 Live Desktop Widgets
Real-time clock, calendar, CPU/RAM usage simulation, and a system-status panel — all updating live, right on the desktop.

</td>
<td width="50%" valign="top">

### 🎨 Custom Wallpaper Studio
Swap desktop wallpapers on the fly, or drop in your own image URL — saved to `localStorage` so it persists across visits.

### 🤖 Built-in AI Assistant
An AI-powered bio assistant lives right in the taskbar, ready to talk about the portfolio owner's story, skills, and work.

### 📲 Installable PWA
Full offline-ready Progressive Web App — install it like a native app on desktop or mobile, complete with a service worker.

</td>
</tr>

**Under the hood:**

- **UI Shell:** Vanilla JS state machine driving windows, taskbar, Start Menu & notification center
- **Interactions:** `jQuery UI` (drag / resize) + `touch-punch` for full mobile drag support
- **Styling:** TailwindCSS (CDN) + custom `glass-panel` frosted UI, glow effects & keyframe animations
- **Fonts:** `Plus Jakarta Sans`, `Space Grotesk`, `JetBrains Mono` — clean, modern, techy
- **Offline Support:** Service Worker (`sw.js`) + Web App `manifest.json` for installability
- **Persistence:** `localStorage` for wallpaper & user preferences

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/hotgi-creative-os.git

# Move into the project
cd hotgi-creative-os

# Just open it — no build step needed 🎉
open index.html
```

> 💡 **No frameworks. No bundlers. No build step.** Everything runs straight from `index.html` using CDN-hosted libraries — clone it and it just *works*.

For the full PWA experience (service worker + install prompt), serve it over a local server instead of opening the file directly:

```bash
# Using Python
python3 -m http.server 8000

# Using Node
npx serve .
```

Then visit `http://localhost:8000` 🚀
